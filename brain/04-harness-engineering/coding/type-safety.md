# Type Safety

> **Load when:** defining types, crossing a boundary, or tempted by an escape hatch. **Rule:** CODE-5.
> Dynamically typed language? Apply the same rules with runtime schemas and type hints.

## 1. Settings

- Type checker / mode: `tsc --noEmit` with `strict`, `noUnusedLocals`, `noUnusedParameters`,
  `isolatedModules` (`tsconfig.json`); run with `npm run typecheck`.
- Runtime schema library: none (zero runtime deps) — hand-written validation in `sanitizeSettings`
  (`src/settings.ts`) and `num()` (`src/widget/dom.ts`).
- Public `.d.ts` files are generated by tsup (`dts: true`) from `src/types.ts` — they are the
  public contract (ARCH-4).

## 2. Rules

- **No escape hatches** without a reason comment: `any`, `as unknown as`, `# type: ignore`,
  non-null `!`, `@ts-ignore`, unchecked casts. Prefer `unknown` + narrowing.
- **Parse at trust boundaries** (DES-3): request bodies, query params, external API responses, env,
  storage, messages → schema → typed value. Never cast external data to a type.
- **Model states, not flags:** discriminated unions / enums instead of several optional booleans.
- **Exhaustiveness:** switch/match over a union handles every case; the default branch asserts never.
- **Narrow public types:** export the smallest type consumers need; return `readonly` where mutation
  isn't intended.
- **One type per concept:** derive DTO/form/DB types from a single source (schema inference,
  generated types) instead of hand-copying.
- **Generated types:** only `dist/*.d.ts` / `*.d.cts` (tsup); never edited by hand. Label types
  derive from `defaultLabels` (`AccessibilityLabels`), so every language must define every key.
- **Nullability is explicit:** `T | null` where absence is meaningful; don't use empty strings/0 as "missing".
- Don't widen a type to silence an error — fix the data flow (CODE-4).
